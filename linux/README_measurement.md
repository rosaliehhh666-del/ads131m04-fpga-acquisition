# ADS 低频测量页

用现有低频 bit，屏端运行 python3 adc_scope.py /dev/ttyUSB0，再打开 http://127.0.0.1:8766/ 。

DC 保留均值，AC 在绘图时减去当前窗口均值。统计表的均值、AC RMS、峰峰值始终按当前窗口计算。通道纵轴独立缩放，跨通道比较幅度请看表格。

拟合栏输入已知激励频率，选择至少覆盖两个周期的时基。拟合采用余弦、正弦及直流分量最小二乘。拟合残差功率超过该路交流功率 10% 时隐藏该路拟合值。CH0 通过资格后才计算幅值比与相位差，正角表示相位领先 CH0，范围为 [-180°, 180°)。该判据适用于同频单音，不能用于证明任意输入的载频已匹配。残差包含噪声、谐波和频率失配。

默认单位为 ADC 码。若已有实测校准系数，可通过 --calibration calibration.json 启用伏特显示。JSON 根节点是四个对象组成的数组，按 CH0 到 CH3 排列。每个对象提供 offset_counts 与 volts_per_count，换算为 (样点码 - offset_counts) × volts_per_count。用同一通道两个已知差分电压点计算斜率与零点。各通道独立标定，系数应按测试接线和量程使用。

零输入噪声测试应保持实际前端连接条件并施加有效的零差分输入，记录窗口内 AC RMS。此页的幅相与噪声读数仍须实板验证。
